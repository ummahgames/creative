## Hosting

Serve this repository as a static webserver document root. Open a game at its folder route, such as /cloud-habitat/. Each game includes its own HTML, JavaScript, CSS, and assets; no installation or shared game-kit folder is needed to play.

This index is generated by the development workspace using `node game-kit/build.cjs`.
